During the recent nepal flood, so many people lost their lives including rescuers.
But what if we could send autonomous vehicles to perform the rescue operations instead of risking human lives. Using stereo cameras as sensors, we can reduce the cost of these UGVs by a lot  And it does not depend on satellites or external networks.
Not just rescue, this has so many different applications. And that is why we chose
vision based autonomous navigation for UGV for outdoor environments as our ps.


Now, time to talk abt the feasibility of our software.
Every package we used is fully open source and no algorithm was made from scratch. This means that we do not need expensive tools to build it.

Usage of stereo cameras instead 3D LIDARS which costs way more money.

Also, data sets for training the model are already readily available.




The impact of this can be huge.
As i previously mentioned, search and rescue operations can take place without costing even more lives. It operates fully offline without needing any connectivity infrastructure and runs on data from cheaper stereo cameras. Also the tech stack does not need to be upgraded for different scenario.
